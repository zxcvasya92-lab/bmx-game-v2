# Street Rider BMX
Оригинальная 3D BMX-игра (Three.js + Capacitor). Сборка APK: залить файлы в GitHub → Actions → Build APK → Run workflow → Artifacts.

## Управление (экранный интерфейс как в PSP-эмуляторе)
- Аналог: руль (влево/вправо), вверх педалить, вниз тормоз. В мануале — баланс.
- ✕ — банни-хоп. Аналог вниз + ✕ — высокий прыжок.
- ○ — мануал (держать; баланс аналогом, следите за полоской). Приземление с зажатым ○ переходит в мануал без потери комбо.
- D-pad (аналог правого стика) в воздухе: ◀▶ — спин, ▲ — бэкфлип, ▼ — фронтфлип. Рейлы: зажмите любое направление D-pad или ○ при заходе на рейл — гринд (вид гринда зависит от направления).
- △ — барспин, □ — тейлвип (в воздухе).
- L / R — спин влево / вправо. Select — респавн, Start — пауза.
- Комбо копится в воздухе, на гринде и в мануале; очки засчитываются, когда вы остановились на колёсах на полсекунды. Падение сжигает комбо.
- ПК: WASD (аналог), Space ✕, M ○, стрелки D-pad, J △, K □, Q/E L/R, Esc пауза.
